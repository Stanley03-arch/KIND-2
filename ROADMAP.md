# Project Roadmap

## Goals
- Keep the Kind engine fast and deterministic for system-one routing tasks.
- Preserve compatibility with TypeSafe-style decision contracts.
- Make local setup and benchmark workflows easy to follow.

## Planned work
1. Improve local benchmark coverage for edge cases.
2. Document configuration patterns for local and hosted setups.
3. Keep secret handling safe and reproducible for contributors.
4. Expand examples for production guardrail use cases.
